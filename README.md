🪙 Coin Toss Game

A simple Coin Toss Game built using Python. The player guesses Heads or Tails, and the computer randomly tosses the coin.

✨ Features

🪙 Toss a coin

🎯 Guess Heads or Tails

🏆 Check whether the guess is correct

🔄 Play multiple rounds

🚪 Exit the game


🛠️ Technologies Used

Python

random module

while loop

if-else

User input


🎯 Learning Purpose

This project helps practice:

random.choice()

while loops

Conditional statements

input()

String methods
